# tg_bot_for_music

Телеграм-бот, который по ссылке скачивает музыку из YouTube Music и присылает её в чат аудиофайлом (mp3 с названием, исполнителем и обложкой).

- **Трек.** Пришли ссылку на песню, получишь mp3.
- **Плейлист или альбом.** Пришли ссылку на плейлист. Бот покажет название и число треков, спросит подтверждение и отправит треки по очереди. Во время загрузки есть кнопка «Стоп», а побитые и недоступные треки пропускаются и перечисляются в итоге.

Ссылки берутся из «Поделиться» в YouTube Music (`music.youtube.com/watch?v=…` и `music.youtube.com/playlist?list=…`), подходят и обычные ссылки youtube.com и youtu.be. Другие сайты бот намеренно не принимает.

## Запуск

Нужны Python 3.10+, [ffmpeg](https://ffmpeg.org/) и JS-рантайм ([Deno](https://deno.com/) или Node.js): без него yt-dlp не справляется с защитой YouTube.

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Установи и запусти:

   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env      # впиши BOT_TOKEN
   python -m musicbot
   ```

Через Docker (в образе уже есть ffmpeg и Node.js):

```bash
cp .env.example .env         # впиши BOT_TOKEN
docker compose up -d --build
```

## Настройки (`.env`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота (обязательно) |
| `ALLOWED_USERS` | пусто = всем | Telegram id через запятую: кому можно пользоваться ботом. Свой id узнай у [@userinfobot](https://t.me/userinfobot) |
| `MAX_PLAYLIST_TRACKS` | 50 | Сколько первых треков плейлиста отдавать за раз |
| `MAX_TRACK_MINUTES` | 30 | Более длинные видео не скачиваются (микстейпы, трансляции) |
| `AUDIO_BITRATE` | 192 | Битрейт mp3, кбит/с |
| `MAX_PARALLEL_DOWNLOADS` | 2 | Сколько загрузок идёт одновременно на всех пользователей |
| `COOKIES_FILE` | пусто | Путь к `cookies.txt`, см. ниже |

Если бот публичный, лучше задать `ALLOWED_USERS`: каждая загрузка тратит трафик и процессор сервера.

## Если что-то не работает

- **«YouTube заподозрил бота».** С IP дата-центров такое случается часто. Выгрузи cookies YouTube в формате Netscape в `cookies.txt` (расширение вроде «Get cookies.txt LOCALLY», лучше из отдельного аккаунта) и укажи путь в `COOKIES_FILE`. В Docker смонтируй файл по примеру из `docker-compose.yml`.
- **Внезапно перестало скачивать.** YouTube регулярно меняется, и yt-dlp приходится обновлять: `pip install -U yt-dlp` (в Docker пересобери образ: `docker compose build --no-cache`).
- **«Файл больше 50 МБ».** Это лимит Telegram для ботов. При 192 кбит/с в него помещается около 35 минут звука.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не ходят в сеть: yt-dlp в них подменён, а Telegram заменён фейковой сессией, которая записывает вызовы API.
